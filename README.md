# Ujaran Kebencian Bahasa Jawa - Detection System

## 🎯 Project Overview
Sistem deteksi ujaran kebencian dalam Bahasa Jawa menggunakan ensemble model transformer.

## 🏆 Best Results
- **F1-Macro**: 89.22%
- **Accuracy**: 89.24%
- **Models**: IndoRoBERTa + BERT Multilingual + XLM-RoBERTa ensemble

## 📁 Project Structure
```
├── src/                    # Source code
├── results/               # Experiment results (JSON only)
├── docs/                  # Documentation
├── requirements.txt       # Dependencies
└── README.md             # This file
```

## 🚀 Quick Start

### Installation
```bash
pip install -r requirements.txt
```

### Training
```bash
python train_model.py
```

### Evaluation
```bash
python evaluate_model.py
```
